# Claude Code

Follow the shared guide: @AGENTS.md

- **Local server:** `.claude/launch.json` defines `taf-demo` on port 5173; start it with the preview tool, not Bash.
- **Builds** can take several minutes. Run them in the background.
- **Visible browser:** hidden preview panes throttle observers and lazy images. Verify motion in a visible browser.
- **Temporary helpers** (mock-ups, one-off scripts, extra servers) go in the scratchpad, never in the project. Remove any temporary `launch.json` entries afterwards.
- **Shared decisions** go in `AGENTS.md` or `docs/`, not here.

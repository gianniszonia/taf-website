# Takis Angelides Furnihome

A static, multilingual (English, Greek, Russian) website concept for TAF, a Cyprus furniture showroom since 1965. It sells the atmosphere of a luxurious home through large room photography, with booking an appointment as the goal.

## Run locally

Requires Node 20+.

```bash
npm ci
npm run build    # makes web images and site/data/catalog.js from content/ (can take a few minutes)
npm start        # http://localhost:5173
```

Rebuild after any change in `content/`. There is no framework or bundler; Sharp optimises the photographs.

## Project structure

```
content/            ← everything the site shows: photos + JSON (source of truth)
  ADDING-IMAGES.md  ← where to put new photos (start here)
  README.md         ← content folders and text rules
site/               ← the website itself (served as-is)
  index.html        page shell
  js/app.js         pages, routing and interactions
  css/styles.css    design and motion
  data/content.js   showrooms, hours, contact details
  data/i18n.js      interface text in en/el/ru
  img/logos/        logos and favicon
  img/brands|inspiration|history/, data/catalog.js   ← generated by the build, not committed
scripts/
  build.mjs         content/ → site/img + site/data/catalog.js
  serve.mjs         local static server
docs/
  design.md         current design decisions
  history.md        how the design got here, and why
  publishing.md     GitHub Pages deployment
  provenance/       sources of brand facts and of the 2026 imports
```

Main pages: home, Products (every piece, filterable by category and brand), Our Brands and each brand, Inspiration and each project, Showrooms, Our Story, Book an appointment and Contact us.

**Current catalogue:** 16 brands (9 with galleries, 7 as outside links), 89 products, 20 inspiration projects, 7 archive photos. Only photographs at least 1600px wide are published. The contact and appointment forms are demonstrations and send nothing.
